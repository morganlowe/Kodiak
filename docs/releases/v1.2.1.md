# Kodiak v1.2.1 — Optional GitHub Update Checker & SHA-256 Verified Downloader

## Executive Summary

Kodiak `v1.2.1` introduces an opt-in GitHub Releases update checker and SHA-256 verified downloader (`check_for_updates = false` by default) tailored to every supported distribution format: Arch/CachyOS split `.pkg.tar.zst` packages, Debian/Ubuntu `.deb` packages, universal Linux AppImages, and both Windows x64 NSIS installers (with and without `ProjectsWiki`). Downloads are strictly restricted to GitHub Releases, verified incrementally with SHA-256 before finalizing, and staged into `~/Downloads/kodiak-updates/v<ver>/` without ever bypassing Kodiak's Hard Deny-List rules against running `sudo` or system package managers.

---

## Key Changes

### Added
- **Optional GitHub Releases Updater (`src-tauri/src/updater.rs`, `src-tauri/src/lib.rs`)**:
  - Queries `https://api.github.com/repos/morganlowe/Kodiak/releases/latest` only when manually requested or when opt-in startup checking is enabled.
  - Detects host platform variant (`arch`, `debian`, `appimage`, `windows-with-wiki`, `windows-without-wiki`) and checks whether `ProjectsWiki` is installed.
  - Downloads selected assets into `~/Downloads/kodiak-updates/v<ver>/`, enforces the GitHub Releases origin allowlist and single-segment filename safety, verifies SHA-256 digests with `sha2::Sha256` before finalizing (deleting `.part` files on mismatch), and provides `check_for_updates`, `download_kodiak_update`, `open_update_download_dir`, `launch_downloaded_installer`, and `skip_update_version` Tauri commands.
- **Configuration Fields (`src-tauri/src/config.rs`, `config.example.toml`)**:
  - Added `check_for_updates: bool` (defaults to `false`) and `skipped_update_version: Option<String>` with backward-compatible `#[serde(default)]`.
- **Desktop Update UI (`src/main.ts`)**:
  - Added a **Software Updates (GitHub Releases)** panel in Settings with opt-in startup toggle, **Check for Updates Now**, companion `kodiak-projectswiki` checkbox for Arch/Debian, **Download & Verify Update**, verified SHA-256 summary, **Open Download Folder**, **Copy Install Command** (e.g. `sudo pacman -U ...`), **Launch Installer** (for Windows `.exe` / Linux `.AppImage`), and **Skip vX.Y.Z**.
  - Added a dismissible **Update Available** banner on Workbench and a **Check for Updates** button + status indicator in About.
- **Unit Tests**: Added 6 Rust tests in `updater::tests` (`91` passing tests total).

### Changed
- Updated package versions, UI labels, `README.md`, `CHANGELOG.md`, and `docs/DECISIONS.md` to `v1.2.1`.

---

## Configuration & Security Notes

- `check_for_updates` defaults to `false` so Kodiak sends zero unsolicited update traffic on startup.
- Consistent with Kodiak Charter Section 4, Kodiak never executes `sudo`, `pacman`, `dpkg`, or `apt`; Arch and Debian users receive a verified local download folder and copyable install command.
