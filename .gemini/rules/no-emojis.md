# Style Rule: No Emojis

- Do not use emojis anywhere in this project.
- This applies to:
  - Application UI (HTML, templates, button labels, icons, notifications, modals)
  - Documentation (README, CHANGELOG, DECISIONS, proposals)
  - Git commit messages, tags, and PR titles
  - GitHub releases and milestone descriptions
  - Assistant communication
- Use clean, professional text labels, standard typography, or CSS/SVG styling instead.
